# 시스템·인프라 엔지니어를 준비하는 김지율
{:.portfolio-title}

Linux 서버와 네트워크를 직접 구성하고, 문제가 발생했을 때 통신 경로와 설정을 나누어 확인하는 과정에 관심이 있습니다. 시스템·인프라 직무 신입으로 서버 운영과 장애 대응 역량을 쌓고 있습니다.

## 프로젝트에서 맡은 역할

- **하이브리드 인프라:** 5명 팀의 팀장으로 참여해 MySQL Master-Master·keepalived VIP, SECUI NGF 방화벽 정책과 정적 라우팅을 담당했습니다.
- **Azure 인프라:** 5명 팀의 팀장으로 참여해 구축 검증을 담당했습니다. Terraform 기반 두 리전 인프라에서 VMSS 확장·웹 계층 장애 대응·DR 전환과 서비스 연결을 확인했습니다.
- **웹·데이터 보안:** WordPress·Apache WEB 서버, lab-sqli.php, Kali 환경과 Hydra·sqlmap 웹 공격 실습을 담당했습니다.
- **행위 기반 보안:** Kali 환경과 SSH Brute Force·Reverse Shell 공격 실습, 결과 보고서를 담당했습니다.

프로젝트 글은 나의 담당 작업과 팀 전체 구축·검증 결과를 구분해 설명합니다.

구축 성공 화면뿐 아니라 정상 상태를 판단한 기준과 장애 후 확인한 결과를 함께 기록하려 합니다. DB 이중화와 웹 계층 DR은 서로 다른 장애 범위를 다루므로, 검증한 조건과 남아 있는 의존 지점을 구분하는 것을 중요하게 생각합니다.

앞으로는 DB 백업·복원과 서버 점검 자동화를 실습하고, 장애 시 복구 시간·실패 요청·복제 지연을 측정해 운영 역량을 보완하려 합니다.
